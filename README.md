## 🔧 Personnalisation

### Changer les couleurs
Modifiez les variables CSS dans `css/style.css`:
```css
:root {
    --primary: #6366f1;      /* Couleur principale */
    --accent: #ec4899;       /* Couleur d'accent */
    --bg-primary: #0f172a;   /* Fond principal */
}
```

### Ajouter des projets
1. Ouvrir `projets.html`
2. Dupliquer une card `.project-card`
3. Modifier le contenu
4. Ajouter `data-category="xxx"`

### Mettre à jour les informations
- Modifier les données directement dans les fichiers HTML
- Utiliser find & replace pour les changements globaux
